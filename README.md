# Koolipraktika IT terviklahendus - Kollanokad

Meeskond: Hedy Kirsipuu, Jaanus Salm, Raili Aas  
Domeen: kollanokad.praktika  
Grupp: 2

Repo sisaldab koolipraktika lahenduse skripte, näidiskonfiguratsioone ja taastamisjuhiseid. Kõik skriptid on kommenteeritud ning tuleb enne lõplikku kasutamist võrrelda tegeliku IP-plaani, liideste nimede ja paroolipoliitikaga.

## Kaustad
- `scripts/` - PowerShelli ja Bash skriptid
- `configs/` - FortiGate, Cisco, Proxmox, HAProxy, NGINX näidiskonfiguratsioonid
- `ansible/` - Linuxi masinate uuendamise Ansible playbook
- `docker/` - Portainer, UniFi Network Application ja Vaultwarden
- `docs/` - taastamis- ja kontrollnimekirjad
